# DSH增强（@xsok/dsh-enhanced）

为 **DeepSeek Harness** 桌面端提供的一组增强能力，核心是**多设备会话同步**：把你在这台机器上的会话、工作区分组、附件与配置，同步到你自己的云端目录（坚果云 WebDAV 或本地共享目录），在另一台机器上无缝接着用。

在此基础上还提供会话删除与找回、跨工作区移动、全库内容搜索、自动加载历史等本地能力。

> 插件同时包含宿主侧（文件与注册表操作）与界面侧（菜单、设置页、弹窗），安装后无需额外配置即可使用本地功能；同步功能需要你自己准备云端目录。

---

## 功能一览

| 分组 | 功能 |
| --- | --- |
| **会话同步** | 本地目录或 WebDAV 双向同步；立即同步、覆盖云端、覆盖本机；同步日志与文件明细；启动与空闲自动同步 |
| 会话管理 | 会话删除（进回收站）、会话找回、保留天数、回收站占用与清理 |
| 阅读与操作 | 自动加载更早消息；跨工作区移动会话 |
| 内容搜索 | `Ctrl+F` 全库搜索，匹配标题 / 消息正文 / 工具输出 |
| 运维 | 环境检测（17 项）、重启应用、冲突与失败诊断 |

### 会话同步做什么

- **会话**：日志双向同步，按“事件数更多的一方更完整”判断方向，不依赖文件时间戳；
- **工作区**：分组、顺序、成员关系合并；分组删除会传播，不被另一台机器加回；
- **配置**：`cordis.patch.yml`、`skills/`、`AGENTS.md`、`.credentials.yaml`（可选）；
- **附件**：对话里粘贴的图片与上传文件（内容寻址，只补不删）；
- **回收站**：双端同步，删除与恢复都能跨机传播；
- **删除传播**：删除会话或分组后，另一台机器同步时也会删掉，不会把它加回来。

## 环境要求

- DeepSeek Harness **0.2.2-rc.1** 及以上；
- Windows 10/11（重启、路径映射等功能依赖 Windows 行为，其他系统未验证）；
- 应用自带的运行环境即可，无需另外安装 Node 或依赖。

## 安装

### 方式一：插件页面安装（推荐）

1. 打开 DeepSeek Harness；
2. 进入 **插件 → 添加插件**；
3. 输入包名 `@xsok/dsh-enhanced`（或本地文件路径 / `.tgz` 文件）；
4. 选择 **安装**，完成后选择 **立即启用**。

### 方式二：本地文件安装

1. 拿到 `dsh-enhanced-<版本>.tgz` 或插件目录；
2. 插件页面 → 添加插件 → 选择本地文件/目录 → 安装 → 启用。

---

## 快速上手

1. 设置 → **DSH增强**，四个分组依次是：阅读与操作、会话管理、内容搜索、会话同步；
2. 本地功能（删除、找回、移动、搜索）默认开启；
3. 需要多设备时，打开“自动同步”，填写同步方式与云端信息。

## 同步配置（WebDAV 示例：坚果云）

| 字段 | 填写 |
| --- | --- |
| 同步方式 | WebDAV |
| WebDAV 地址 | `https://dav.jianguoyun.com/dav/` |
| 账号 | 坚果云登录邮箱 |
| 应用密码 | 坚果云 → 安全选项 → **添加应用密码**（不要用登录密码） |
| 远程根目录 | `/我的坚果云/DSH-Sync`（首尾斜杠可省略，反斜杠也行） |
| 本地镜像目录 | 留空则默认 `%LOCALAPPDATA%\dsh-enhanced\webdav-mirror` |

建议先点 **测试连接**，再点 **立即同步**。

### 两台以上机器

1. 每台机器安装插件；
2. 机器标识不要相同（留空默认取 Windows 用户名；重名会中止同步并列出冲突项）；
3. 首次同步会完整拉取，之后按内容增量传输；
4. 同一会话不要在两台机器上同时继续对话——会话日志是追加文件，同步只能整份取舍，不能合并。

### 覆盖功能

| 按钮 | 作用 | 风险 |
| --- | --- | --- |
| 覆盖云端 | 用本机数据完整替换云端，不做合并 | 云端独有文件会被删除 |
| 覆盖本机 | 用云端数据完整替换本机，不做合并 | 本机独有的同步数据会被删除 |

两者都会写一条同步记录，本机覆盖后会自动重启以生效。

## 运维功能

- **环境检测**：检查宿主服务、Node 能力、会话/工作区/标题/附件目录结构、数据目录可写性等；异常可在桌面导出 Markdown 报告；
- **重启应用**：设置页按钮或 `Ctrl+Shift+Alt+R`，用于让“移动会话 / 覆盖本机”等结构变化立即生效；
- **版本提醒**：主程序版本变化时弹窗提示运行环境检测，标题带插件名，避免来源不明的弹窗。

## 数据与隐私

插件只在本机读写以下位置：

| 路径 | 内容 |
| --- | --- |
| `%USERPROFILE%\.dsh\sessions` | 会话日志 |
| `%USERPROFILE%\.dsh\storages` | 工作区登记、标题缓存 |
| `%USERPROFILE%\.dsh\attachments\v1` | 对话附件 |
| `%USERPROFILE%\.dsh\dsh-enhanced` | 插件设置、回收站、同步记录与日志 |

同步开启后，上述**会话、工作区、标题缓存、附件、配置（含 `.credentials.yaml`）**会上传到你自己配置的云端目录。请确认云端目录的可见范围符合你的预期。

插件不含任何内置账号、密钥或遥测；除你配置的 WebDAV 地址外不会访问网络。

---

## 卸载与清理

```text
1. 插件页面 → 禁用 / 卸载
2. 需要彻底清理时，删除 %USERPROFILE%\.dsh\dsh-enhanced
3. 会话、附件等业务数据不会随插件卸载删除
```

卸载不会删除 `~/.dsh` 下的会话与工作区数据。

## 常见问题

**同步失败，提示云端限流（HTTP 503）**
坚果云对短时间内大量请求会限流。插件会自动重试并在冷却后恢复；失败时日志会写明建议，等几分钟再同步即可。

**移动会话后列表位置不对**
移动会改写会话的工作目录并更新工作区分组，需要重启应用才完全生效；插件在移动完成后会自动重启。

**回收站里出现“未命名”**
该会话在删除时没有生成标题。列表仍显示原始会话 ID，可在日志中按 ID 查找。

**要不要开“同步附件”**
关闭后会话文字照常同步，但含图片的会话在另一台机器上无法继续对话（模型读取图片时会失败）。两台都要正常用请保持开启。
